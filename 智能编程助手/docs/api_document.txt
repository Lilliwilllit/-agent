# 项目 API 接口文档 v1.0

## 1. 用户认证模块
本模块负责处理用户的登录与注册请求。

### 1.1 用户登录
- **接口地址**: /api/v1/login
- **请求方式**: POST
- **请求参数**:
    - username (string): 用户名，必填
    - password (string): 密码，必填
- **返回示例**:
    {
        "code": 200,
        "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "message": "登录成功"
    }

### 1.2 用户注册
- **接口地址**: /api/v1/register
- **请求方式**: POST
- **描述**: 创建一个新的用户账户。
- **注意**: 密码长度不得少于 8 位。

## 2. 数据查询模块
### 2.1 获取用户信息
- **接口地址**: /api/v1/user/{id}
- **描述**: 根据用户 ID 获取详细信息。
