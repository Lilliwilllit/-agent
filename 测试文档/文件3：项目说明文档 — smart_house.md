# Smart House - 智能家居设备模拟系统

## 项目简介

一个纯 Python 实现的智能家居设备模拟系统，使用字典和函数参考模拟面向对象编程，演示设备管理、功耗计算和连接控制等核心功能，无需依赖外部框架。

## 技术特点

- **轻量化实现**：100% 标准 Python，无第三方依赖
- **设备类型**：灯光、温控器、摄像头
- **核心功能**：设备生命周期管理、功耗动态计算、设备连接控制、统一管理接口
- **测试覆盖**：内建单元测试套件

## 快速开始

```bash
# 从项目根目录运行演示
python smart_house.py

# 运行单元测试
python test_smart_house.py
```
